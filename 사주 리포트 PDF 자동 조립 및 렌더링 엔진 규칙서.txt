# 🎨 사주 리포트 PDF 자동 조립 및 렌더링 엔진 규칙서 (v5.0 Lite)

---

## 0. 콘텐츠 원문 보존 원칙 (필수)
* PDF 조립 엔진(렌더러)은 사주 풀이 지침에 따라 이미 생성·검증까지 끝난 리포트 원문(report_markdown)을 **그대로** PDF로 옮기는 역할만 한다.
* 렌더링 과정에서 AI가 문장을 다시 쓰거나, 요약하거나, 표현을 바꾸거나, 새로운 문장을 추가하는 **재해석·재생성은 금지**한다.
* 렌더러가 하는 일은 오직: 마크다운 구조(제목·불릿·표·인용구·패턴 A/B/C 등)를 인식해서 시각적 컨테이너(카드·표·하이라이트 등)로 배치하는 것뿐이며, 문장 자체의 글자 하나도 임의로 바꾸지 않는다.
* 사주 원국 스냅샷(십성·오행·대운·용신 등 수치 데이터)은 리포트 원문이 아니라 항상 saju_data(JSON) 원본에서 직접 읽어 렌더러 코드가 그린다 — 이 데이터도 AI가 다시 계산하거나 고쳐 쓰지 않는다.

---

## 1. 전역 스타일 및 캔버스 규격
* **판형**: A4 세로 (`210mm x 297mm`)
* **여백(Margin)**: 상하 `25mm`, 좌우 `20mm`
* **배경 질감**: 미색 한지 텍스처 베이스 (`#F9F8F3`)
* **족자 프레임**: 표지를 제외한 전 페이지 상단(Top `12mm`)과 하단(Bottom `12mm`)에 가로 족자 봉 일러스트 바 고정 렌더링
* **기본 폰트**: 
  * 본문: KoPub돋움 또는 프리텐다드 (`#2B2B2B`, Line-height `1.75`)
  * 타이틀/강조: KoPub바탕 또는 나눔명조
* **포인트 컬러**: 전통 와인 버건디 (`#A3344B`)
* **오행(五行) 5색 블록 컬러 규격 (글자색 공통 #FFF)**:
  * 목(木): `#4E788B` (청회색)
  * 화(火): `#D26E6E` (인디핑크/적색)
  * 토(土): `#C89B54` (황토/머스터드)
  * 금(金): `#8F8E8C` (은회색)
  * 수(水): `#384B66` (다크 네이비)

## 2. 표지 (제1장) 전용 렌더링 규칙
* **배경**: 명리학/동양화 고풍 산수화 한지 일러스트 (전체 핏)
* **레이아웃**: 페이지 정중앙 수직·수평 센터 배치
* **중앙 텍스트 블록**:
  1. **상단 서브 타이틀**: `답답명쾌 사주 해답소` (16pt, 바탕체, `#5C5247`, 자간 `0.15em`)
  2. **메인 타이틀**: **프리미엄 사주 해답지** (38pt, 볼드, `#1D2D44`, 자간 `-0.02em`)
  3. **하단 메타 정보**: `분석 대상: {이름} 님 | 기준 명식: {간지 명식}` (11pt, 라운드 반투명 화이트 박스)

## 3. 원국표(스냅샷) 및 동적 하이라이트(Focus) 규칙
* **크기 제한**: 스냅샷 블록(9행 표+대운/용신 정보) 전체는 한 페이지 높이의 **약 1/3 이내**로 축소 배치한다. 본문 해설과 나란히 봤을 때 스냅샷이 페이지의 2/3 이상을 차지하지 않도록, 셀 여백·폰트 크기·행 간격을 전체적으로 축소한다.
* **오행 막대그래프는 여기 포함하지 않는다** — 반복되는 스냅샷마다 오행 분포 막대를 다시 그리지 않고, 오행을 다루는 제5장(명식/오행 챕터)에서만 별도로 1회 표시한다.
* **스냅샷 9행 구조**: 가로 4열(`시주 | 일주 | 월주 | 년주`) x 세로 9행:
  1. 십성(천간) — 예: 정재/비견/정인/편인
  2. 음양오행(천간) — 예: 丁(음화)
  3. 천간 (큰 박스, 한글 독음 + 한자, 오행 색상 배경)
  4. 지지 (큰 박스, 한글 독음 + 한자, 오행 색상 배경)
  5. 음양오행(지지) — 예: 未(음토)
  6. 십성(지지) — 예: 정관/편재
  7. 십이운성 — 예: 양/태/절/관대
  8. 십이신살 — 예: 반안살/장성살 (없으면 `—`)
  9. 귀인 — 현재는 천을귀인만 정확히 계산되어 표시됨. 그 외 귀인(천덕귀인·천관귀인 등)은 올바른 명리 공식이 검증되기 전까지 지어내지 않고 `—`로 비워둔다.
* **챕터별 포커스 CSS 룰**:
  * **활성 셀(Focus)**: `outline: 2px solid #A3344B; opacity: 1.0;`
  * **비활성 셀(Dimmed)**: `opacity: 0.32; filter: grayscale(40%);`
* **챕터 매핑 기준**:
  * **제5장 (명식/오행)**: 9행 전체 활성화(dim 없음) + 오행 막대그래프 1회 표시
  * **제6장 (일주론)**: `[일주(日柱)] 열 전체(9행)` 하이라이트
  * **제7장 (생애 4주기)**: 전체 활성화
  * **제8장 (격국)**: `[월지 관련 행: 지지·음양오행·십성·십이운성·십이신살·귀인]` 집중 하이라이트
  * **제9장 (진로/직업)**: `[월주 열 전체]` + `[관성 십성 셀]` 활성화
  * **제10~11장 (재물/자산방어)**: `[일주 열 전체]` + `[재성 십성 셀]` 활성화
  * **제12장 (인간관계/애정)**: `[일지 관련 행]` 집중 하이라이트
  * **제13장 (건강운)**: 전체 활성화(오행 상극 셀 동시 하이라이트는 추후 고도화 과제로 남김)

## 4. 프로필 카드 (제4장 "사주 스냅샷" 전용, 리포트 전체에서 1회만 노출)
* **구성**: 일주 동물 아이콘 + `{이름} 님 ({성별})` + `생년월일: {날짜}` + `오행: {일간 음양오행} · 일주 동물: {동물명}` + 안내 문구(※ 일주 동물은 실제 동물이 아니라 일주의 기운을 상징적으로 표현한 메타포)
* **일주 동물 아이콘**: 정식 커스텀 일러스트 에셋(`character_{일간색상}_{일지동물}.png` 등)이 아직 없어 이모지로 대체 중 — 추후 에셋이 준비되면 교체한다.
* **제4장 페이지 구성**: 프로필 카드 바로 아래에 9행 원국표(전체 활성화, dim 없음)를 이어서 배치한다. 이 페이지는 AI가 쓴 문장이 아니라 원국 데이터만으로 코드가 그린다.

## 5. 텍스트 ➔ 카드 UI 자동 파싱 룰
텍스트 내부의 특정 패턴을 감지하여 컨테이너 박스로 자동 변환:
1. **패턴 A: `직장에서의 모습:` / `갈등 상황:` / `일상의 욕망:` 감지 시**
   ➔ 2분할/3분할 화이트 카드 그리드(`background: rgba(255,255,255,0.85); border-radius: 10px; padding: 14px;`)로 배치
2. **패턴 B: `DON'T (절대 피할 3가지)` / `DO (당장 실천할 3가지)` 감지 시**
   ➔ 버건디 뱃지 헤더가 달린 2단 대조형 카드 블록으로 변환
3. **패턴 C: `[특징]` / `[실생활 영향]` 감지 시**
   ➔ 상단 특징 박스 + 하단 들여쓰기 영향 설명 박스로 자동 인덴트

## 6. 페이지 넘김(Pagination) 제어
* **챕터 구분 페이지**: 매 챕터(제N장)는 본문과 분리된 별도의 한 페이지를 갖는다. 이 페이지에는 챕터 번호와 제목만 페이지 중앙에 크게 배치하고, 원국 스냅샷이나 본문 내용은 이 페이지에 함께 넣지 않는다. 본문(스냅샷+해설)은 반드시 다음 페이지부터 시작한다.
* `제N장` 타이틀 및 소제목 뒤 페이지 분할 방지: `page-break-after: avoid;`
* 테이블 및 카드 블록 내부 분할 방지: `page-break-inside: avoid;`
* 표지를 제외한 2장부터 하단 중앙(Bottom `8mm`)에 `— {page} —` 페이지 번호 자동 출력
